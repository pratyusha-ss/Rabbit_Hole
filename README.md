Rabbit Hole
Rabbit Hole is a small adventure game I made using HTML, CSS and JavaScript. You explore different rooms and choose what you want to do. Some choices give you more points and some choices let you find items. JavaScript How to Play Start the game. Choose one of the three options. Explore the next room. Try to get the highest score. Find mystery items along the way! I wanted to make a simple game where the player can make choices and see what happens next. I also wanted to practise using JavaScript to make a webpage interactive.
