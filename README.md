# 🐇 The Rabbit Hole

> **One question. Infinite directions.**

The Rabbit Hole is an AI-powered exploration game that turns curiosity into an adventure.

Start with any question. Get a real answer. Then choose one of three connected questions and go deeper.

Before you know it, a simple question can lead somewhere completely unexpected.

---

## 🧠 How It Works

The Rabbit Hole follows a simple loop:

**ASK → ANSWER → CHOOSE → EXPLORE → REPEAT**

1. Ask the Rabbit Hole anything.
2. The AI explains the answer.
3. Three connected questions appear.
4. Choose the path that interests you.
5. Keep going deeper.

Every question becomes a doorway to another idea.

---

The internet contains an incredible amount of knowledge, but discovering it can feel random.

We wanted to create something different:

**A game that makes people want to learn things they never intended to learn.**

The Rabbit Hole combines the feeling of:

- 🔎 Google

- 🧩 A mystery game

- 🤖 AI exploration
